# Planet Falconia

Rover control and visualization code for "Planet Falconia: Mission Possible", a
three-year STEM project at Poolesville High School run with researchers at the National
Institute of Standards and Technology.

Students designed and built remotely operated rovers, drove them across a physical
model of a fictional exoplanet, and explored the same terrain in virtual reality. A
LiDAR scan of the model was captured with an iPhone, imported into ParaView alongside
simulated remote sensing data, and viewed in Immersive ParaView, developed at NIST. A
ceiling-mounted Raspberry Pi camera running OpenCV tracked the rovers by fiducial
markers and streamed their live positions into the 3D scene.

This work was presented at the Johns Hopkins Applied Physics Laboratory XR Symposium in
2025, and accepted to the SIGGRAPH Asia 2026 Educator's Forum.

Contains the ParaView state file, the VR and tracking launch scripts, and the client and
server components. Archived, not maintained.
